# Thư mục Dữ liệu (Data)

Thư mục này chứa dữ liệu bộ nhớ đệm (cache) được tải tự động từ OpenML thông qua module `src/data_loader.py`.

- Các file dữ liệu định dạng `.npz`, `.csv` hoặc thư mục cache OpenML được quản lý cục bộ và tự động bỏ qua bởi `.gitignore` nhằm đảm bảo repository luôn gọn nhẹ theo quy định của môn học.
- Để tải và cập nhật dữ liệu, chạy trực tiếp: `python src/data_loader.py`.
